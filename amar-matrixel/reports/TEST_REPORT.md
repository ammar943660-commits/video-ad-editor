# تقرير الاختبار الصادق — AMAR Matrixel Visual Reconstruction

> التاريخ: 2026-10-23 · بيئة الاختبار: حاوية سحابية (Linux، 4 أنوية، بلا GPU — WebGL برمجي SwiftShader)، Chrome + three.js r186 + OpenCV 5 + Tesseract (عربي).
> **لا يوجد في هذه البيئة: Premiere Pro · After Effects · Blender · لقطات درون حقيقية · GPU.** كل ما يتعلق بها مصنّف أدناه بصدق.
> التفاصيل الرقمية الكاملة: [`TEST_REPORT.auto.md`](TEST_REPORT.auto.md) (مولَّد آلياً) + `projects/*/*/qa_report.json` + [`camera_qa.json`](camera_qa.json) + [`reuse_policy.json`](reuse_policy.json).

## 0) أهم تحفّظ: ماذا يعني «ناجح» هنا
- المواد الاختبارية **تركيبية** (لقطة أرض وواجهة فيلا مولَّدتان بـthree.js بكاميرا معلومة). فائدتها أنها تعطي **Ground Truth** (كاميرا حقيقية لكل فريم) فنقيس دقة التتبع والمنظور رقمياً — لكنها **ليست لقطات درون حقيقية**: لا ضجيج حسّي، لا ضبابية حركة، لا عوائق، لا تغيّر تعريض. أداء التتبع على لقطة حقيقية **غير مُختبر**.
- المراجع الستة المرفوعة (تسجيلات شاشة لواجهة Matrixel) استُخدمت **للتحليل البصري فقط** (لم تُستخدم كمادة اختبار: تحوي واجهة طرف ثالث ومحتوى مولَّد). تحليلها: (1) نص ذهبي متناثر على أرض، (2) نص حجري + حدود نيون، (3) أرض ثلاثية الأبعاد بمساحة ومبنى Wireframe، (4) واجهة فيلا بخطوط نيون وبطاقات عربية، (5)(6) انتقال ساعة ذهبية/نهار↔ليل لواجهة. **(1) و(5)(6) خارج الوصفات الأربع المطلوبة ولم تُنفَّذ** (انظر §3).
- بوابات الجودة (`direction/director.json`) وُضعت قبل القياس، ثم عُدِّلت الوصفات حتى تمر (انظر §4: ما الذي فشل أولاً وكيف صُحّح) — العتبات لم تُرخَّ لتمرير النتائج، إلا ما ذُكر صراحةً.

## 1) ✅ مختبر وناجح (على مواد اختبار تركيبية بحقيقة أرضية)

| البند | الدليل |
|---|---|
| **معادلات الكاميرا** (pose ↔ three.js) | اختبار وحدة: إسقاط three مقابل إسقاط pose = **8×10⁻¹⁴ px** |
| **ثبات التتبع** (Planar Track لأرض/واجهة) | اهتزاز عالي التردد **0.004–0.028 % من العرض** (≤ 0.15px على 540px)؛ 0 فريم مفقود في كل التشغيلات |
| **دقة التتبع** | خطأ متوسط **0.16–0.41 % من العرض** (1.6–2.2px على 540px، يشمل خطأ نقر المستخدم المتعمَّد ±1.5px) — العتبة 0.5 % |
| **دقة المنظور** (نقاط 3D على الأرض وعلى ارتفاع النص/المبنى) | **0.12–0.33 %** من العرض (العتبة 0.8 %) |
| **A · التصاق النص بالأرض** | خطأ التلامس **0.04–0.14 %**؛ نسبة العناصر الطافية خارج حجم (نص+غبار+حطام) **≤ 0.03 %** (العتبة 1.5 %) |
| **B · حدود الأرض Neon** | الخط مقابل الحدود الحقيقية **0.23–0.42 %** (يشمل خطأ النقر)؛ مساحة «2000 م²» تُقرأ بعد إزالة المنظور (OCR 0.89–1.0) |
| **B · قواعد الصدق** | 4 اختبارات سلبية: مبنى بلا `approved`، `approved` بلا `source`، مساحة نصية، مخطط غير معتمد → **كلها رُفضت** عند الريندر. شارة «تصور مبدئي — غير معتمد» حاضرة في كل فريمات المبنى (فحص آلي، 0 مخالفة) |
| **C · انزلاق خطوط الواجهة** | **0.10–0.19 %** من العرض (≈1px متوسط) — الخطوط تُكتشف مرة واحدة وتُتبَّع |
| **C · البطاقات العربية** | اهتزاز موضع **0.04–0.11px**؛ 0 تداخل؛ وضوح OCR **0.92–0.98** (1080×1920: 0.94) |
| **D · حركات الكاميرا** | Tilt Up · Push-In · Rise (محاكاة) · Rise/Push/Parallax **بعمق** على 9:16 و4:5 و16:9: كلها تمر (تغطية حواف، تسارع/تباطؤ ناعم، Jerk ≤ 0.01، تطابق الحركة المقاسة بـPhase-Correlation مع المسار ≥ 0.995) |
| **D · الرفض الصحيح** | Parallax بلا depth → **رُفض** (رمز 3)؛ مصدر صغير + حركة كبيرة → **رُفض** (رمز 4)؛ Rise كامل على 16:9 → رُفض (لا Overscan رأسي كافٍ)، ونسخة `--amount 0.5` تمر |
| **D · التثبيت** | فيديو باهتزاز يدوي صناعي: الاهتزاز نزل **3.98×** (العتبة 2×) |
| **النسب 9:16 · 4:5 · 16:9** | المصفوفة الكاملة 3×3 (A,B,C) + D: كلها تُنتج المقاس الصحيح وتجتاز البوابات؛ المنطقة الآمنة 0 مخالفة |
| **إعادة الاستخدام** | نفس المحرك بـJSON مختلف (نصان متتاليان بخامة رملية على 16:9 · هولوغرام بلا مساحة + مبنى معتمد على 4:5 · بطاقات بلون ذهبي على 9:16) — كلها pass بلا تعديل كود |
| **جودة التصدير الأساسي** | 1080×1920: `overlay.mov` ProRes 4444 + ألفا، `overlay.webm` VP9 + ألفا، `preview.mp4` بصوت |

## 2) 🟡 منفذ ويحتاج تصحيحًا

| البند | الحالة والسبب | المطلوب |

| **C · واجهة مستوية واحدة** | المباني متعددة الأسطح تحتاج سطحاً لكل واجهة | `planes[]` غير منفذ بعد |

## 3) ❌ غير منفذ
- **أي اختبار على لقطات حقيقية** (درون/كاميرا): لا مادة متاحة؛ التتبع تحت الضوضاء/الحجب/تغيّر التعريض/الضبابية غير معروف.
- **مؤثر النص الذهبي المتناثر** (مرجع 1) و**انتقال نهار↔ليل/الساعة الذهبية** (مراجع 5-6): خارج الوصفات المطلوبة. الثاني يحتاج AI relight (Magnific/غيره) — **مدفوع، لم يُستدعَ بلا موافقتك**.
- **مشاريع أصلية قابلة للفتح**: `.aep` / `.prproj` / `.blend` فعلية (المنتَج سكربتات/XML تبنيها).
- **تقدير اتجاه الشمس/لون الإضاءة تلقائياً**، **اكتشاف حدود الأرض تلقائياً** (النقاط من المستخدم عمداً)، **تتبع أسطح متعددة**، **استيراد نموذج معماري**، **توليد زوايا بـAI** (عمداً: «لا اختلاق»).
- **Premiere كمصدّر نهائي**: التصدير النهائي يتم في Premiere بعد الاستيراد؛ لم يُنفَّذ هنا.

## 4) ما فشل أولاً وكيف صُحّح (سجل أمين)
1. **تتبع الأرض**: التشغيل الأول فقد التتبع من الفريم ~88 (خطأ 13px، 27 % فريمات معلَّمة) ← أُعيدت هندسة المتتبع (ECC تزايدي بين الفريمين + تصحيح انجراف مقابل الفريم الأول + SIFT صارم) ← 0 فريم مفقود، خطأ 1.6px.
2. **انزلاق خطوط الواجهة 109px** كان خطأ في اصطلاح أصل المستوى بملف الـGround Truth (لا في الأداة) ← وُحّد الاصطلاح ← 1px.
3. **النص الحجري غير مقروء** (OCR 0.33، «reject») ← أضفنا ميلاً للخلف `lean_deg`، وخففنا ضوضاء/شقوق الخامة ← يُقرأ ويمر.
4. **أخطاء QA نفسها**: فشل OCR لبطاقة مقروءة (psm خاطئ)، تقريب صندوق البطاقة أنتج «اهتزازاً» وهمياً 0.66px، حطام صغير دخل صندوق النص، وfalse-positive للطافي مع beats متعددة ← صُحّحت أدوات القياس لا العتبات.
5. **16:9 / 4:5**: أبعاد فردية (540×675) كسرت libx264 ← أبعاد زوجية؛ بطاقة 16:9 خرجت من المنطقة الآمنة ← قصّ بحسب الأبعاد المقيسة.
